# The lander

A fictional descent vehicle, inspired by lunar landers but with its own values,
chosen so that flight is understandable.

| Item                  | Value                                     |
| --------------------- | ----------------------------------------- |
| Mass without fuel     | 1,200 kg                                  |
| Tank                  | 300 kg (the first descent carries 60 kg)  |
| Maximum thrust        | 4,500 N                                   |
| Lunar gravity         | 1.62 m/s²                                 |
| Maximum turn rate     | 30°/s on each axis                        |
| Centre of mass height | 1.5 m above the feet                      |
| Legs                  | Four, 1.5 m from centre in each direction |

With 60 kg aboard the lander weighs 1,260 kg and hovers at 45% throttle. With a
full tank it would need 54%.

The engine and the attitude thrusters share fuel: turning costs fuel too. There is
no air on the Moon, so nothing slows you down except your own thrust.
