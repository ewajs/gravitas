# El módulo

Un módulo de descenso ficticio, inspirado en los landers lunares pero con
valores propios, pensados para que el vuelo sea comprensible.

| Dato                      | Valor                                        |
| ------------------------- | -------------------------------------------- |
| Masa sin combustible      | 1200 kg                                      |
| Tanque                    | 300 kg (el primer descenso carga 60 kg)      |
| Empuje máximo             | 4500 N                                       |
| Gravedad lunar            | 1,62 m/s²                                    |
| Velocidad de giro máxima  | 30°/s en cada eje                            |
| Altura del centro de masa | 1,5 m sobre las patas                        |
| Patas                     | Cuatro, a 1,5 m del centro en cada dirección |

Con 60 kg cargados, el módulo pesa 1260 kg y flota con un 45 % de empuje. Con el
tanque lleno necesitaría un 54 %.

El motor y los propulsores de actitud comparten combustible: girar también
gasta. En la Luna no hay aire, así que nada te frena salvo tu propio empuje.
